What would move each level up

A pure-logic test for the wallet commission path would lift unit. A run against the live backend would lift integration. A first device run would lift system and acceptance together. Deploying and executing the rules, and moving the remaining image blobs out of the database, would lift production. None of those steps has been taken, which is why every level still reads partial.

What has not been proven

  • Nothing has been run on a device or emulator. An attempt is impossible on this machine: the only emulator profile points at an empty system image, and no hypervisor driver is installed.
  • The database rules have never been executed. They are authored, not deployed and not tested.
  • The minified release build has never been run, because it is unsigned and cannot be installed as produced.
