What blocks a demo, and what is production only

The two lists are different kinds of work. The first stops a live demo, the second can wait for production.

Blocks a demo

  • A real device run, since the app has never been executed.
  • The two accepted risks, if the demo touches shared matching.

Production only

  • The undeployed database rules.
  • The inline image blobs that should move to file storage.
  • The remaining whole-node reads.
  • The unsigned release build.
